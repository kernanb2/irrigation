Unit E Wiring

The complete Unit E wiring: 12V supply, LM2596, ESP32, Songle 8-relay module and all five valves, wired through color-coded DIN rail terminal blocks.

Grounds: yes, every negative goes back to one place.

The green blocks (Gn1–Gn5) are bridged into one ground bus. The 12V supply −, the LM2596, the ESP32, the relay module and every valve's return land there. The 5V rail shares that ground through the LM2596. The 3.3V rail is made on the ESP32 board itself, so its negative is the ESP32's GND. Unit E has no 9V rail; that's Unit A, which is a separate box with its own ground. Two things must not join this bus: the XKC-C352 pump controller's 0V, and the Omnitrol's dry contacts, which have no ground of their own.

Header: VCC → ESP32 3V3, GND → ESP32 GND, JD-VCC → Bk2 (5V), JD-header GND → Gn2. Pull the JD-VCC↔VCC jumper. All eight coils at once draw about 0.6A from the 5V rail, which the LM2596 handles easily. GPIO numbers are the same as before, so the firmware doesn't change.

Don't connect any IN pin to the ESP32 until step 5 passes.

The old module's IN1 read 9V, and that probably killed GPIOs 22 and 23. Every IN pin on the new module must read 3.3V or less before a GPIO touches it.

Build and test, one stage at a time

  1. Rail and 12V. Mount the blocks and fit the bridges for red, green and black. Supply + → F1 → R1, and supply − → Gn1. Power on and check for 12V from each red block to each green block. Power off.
  2. 5V. Wire the LM2596 to R1 and Gn1, with its output disconnected. Set it to 5.0V, then connect OUT+ to Bk1. Check for 5.0V on Bk1–Bk3.
  3. ESP32. Connect Bk1 → VIN and ESP32 GND → Gn2. It should boot and join WiFi (solid blue LED). Unplug VIN before you plug in USB to flash, and flash the current firmware (GPIO 21 for the tank drain). Then check the GPIOs with nothing connected: 26, 27, 25, 33, 32, 13 and 21 should all read 3.3V.
  4. Relay module power. Pull the jumper, then wire JD-VCC → Bk2 and JD GND → Gn2. Wire VCC → ESP32 3V3 and GND → ESP32 GND. Don't connect any IN wires yet.
  5. IN pin check. Measure IN1–IN8 to GND. Each should read 3.3V or less. Touch each IN to GND in turn: its LED should light and its relay should click. If any IN reads above 3.3V, stop and tell me.
  6. Logic wires. Run GPIO 26, 27, 25, 33, 32, 13 and 21 to IN1–IN7. Every relay should stay off.
  7. Filter 1. Wire F2/Gy1/Y1 and the valve to Gy1, Y1 and Gn3. Press Flush now on the web page. The valve should open, then close.
  8. Filter 2. Same as filter 1, using F3, Gy2 and Y2.
  9. Storage Tank Drain. F6, Gy5 and Y3, with blue to Gn4. Don't press Drain Tank until the Pond Drain and Pond Fill work: Drain Tank moves them first.
  10. Pond Drain. Jumper K3 NC to K4 NO and run the pair to Gy3. Run K3 NO and K4 NC to Gn4, and K3/K4 COM to Bu1/Bu2. Fit F4 (2A). With the relays off, it should drive closed. Test Open, 50% and Close.
  11. Pond Fill. Same pattern on K5/K6, using Gy4, Gn5 and Bu3/Bu4, with F5 (2A). With the relays off it should drive open. If it goes the wrong way, swap the red and black on Bu3/Bu4.
  12. Last. Start a 10-minute Drain Tank run. The Pond Drain should go to 100% and Pond Fill should close; then the tank drain should open. Press Stop draining: the tank drain should close and the other two return.
